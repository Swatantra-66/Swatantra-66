## ❖ About Me

I am a **Backend & Distributed Systems Engineer** focused on building high-throughput, fault-tolerant architectures and production-ready cloud services.

- **Distributed Systems:** Engineering concurrent Go microservices, event-driven pipelines, and low-latency REST/gRPC APIs.
- **Cloud Infrastructure:** Architecting resilient, secure workloads on **AWS** (Certified) using Docker and Nginx reverse proxies.
- **Data & Transactions:** Managing complex relational modeling, query optimization, and strict ACID guarantees across PostgreSQL and Redis.
- **Security & Reliability:** Implementing zero-trust auth/IAM systems, distributed rate-limiting, and cryptographic audit trails.
- **Engineering Core:** Prioritizing observability, predictable failure modes, and low latency under peak load.
